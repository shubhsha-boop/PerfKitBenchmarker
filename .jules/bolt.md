## 2024-05-14 - Avoiding unnecessary object allocation in loops with defaultdict
**Learning:** In Python, `dict.setdefault(key, default_obj)` evaluates the `default_obj` parameter on every single iteration of the loop before checking if the key exists. When used inside a high-frequency loop (e.g., iterating over thousands of benchmark samples), this creates thousands of unnecessary object allocations (like `set()` or `[]`) that are immediately discarded, causing memory allocation overhead and increased execution time.
**Action:** Replace `dict.setdefault(key, default_obj)` with `collections.defaultdict(default_factory)` for dictionary initialization within loops to defer the creation of the default object until a missing key is actually encountered, resulting in a measurable performance improvement and reduced memory allocations.
