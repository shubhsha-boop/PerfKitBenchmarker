## 2024-04-15 - [Python dict.setdefault in hot loops]
**Learning:** Using `dict.setdefault(key, set())` inside a hot loop (like iterating through sample metadata) forces Python to allocate a new, empty `set()` on every single iteration, even if the key already exists. This causes significant memory allocation and garbage collection overhead. Furthermore, calling `frozenset(dict)` inside a loop recomputes the frozenset on every iteration, which is extremely expensive compared to doing it once outside the loop and using `.keys()` (which creates a dictionary view, supporting fast set difference).
**Action:** Replace `setdefault(k, set())` with `.get(k)` combined with a lazy initialization (`if s is None: s = set(); d[k] = s`). Hoist `frozenset` generation outside loops when the underlying dictionary keys do not change during iteration.
