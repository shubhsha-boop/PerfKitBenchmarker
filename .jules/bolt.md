## 2026-11-11 - Optimize Python String Serialization Performance
**Learning:** In hot serialization paths, replacing traditional loops utilizing `.append()` and `%` string formatting with list comprehensions and f-strings (e.g., `[f'{k}:{v}' for k, v in dict.items()]`) yields measurable performance speedups. Similarly, passing a list comprehension to `str.join()` (e.g., `' '.join([f'{k}={v}' for k, v in dict.items()])`) executes significantly faster than passing a generator expression.
**Action:** Always prefer list comprehensions and f-strings for string concatenation and formatting over `.append()`, `%` formatting, and generator expressions when performance is a priority.
